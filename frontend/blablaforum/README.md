# BlablaForum

Веб-приложение форум.


### Ссылка на макет в Figma
[Макет интерфейса BlablaForum](https://www.figma.com/design/E982humw7J1NF2vLMNprOg/BlaBlaForum?node-id=99-2&t=TY0FrSIYOL51hF5a-1)

### Назначение макета
Макет разработан для визуализации пользовательского интерфейса веб-приложения форума. Он отражает основные пользовательские сценарии и служит основой для frontend-разработки.

### Реализованные экраны
1. **Главная страница (Список разделов)** - отображение всех доступных разделов форума с навигацией
2. **Страница раздела (Список тем)** - просмотр тем внутри выбранного раздела
3. **Страница создания треда** - форма для создания нового треда
4. **Страница регистрации** - форма для создания нового аккаунта
5. **Страница входа** - форма для авторизации пользователя

### Пользовательские сценарии
- **Регистрация и вход**: пользователь создает аккаунт или входит в систему
- **Навигация по форуму**: просмотр разделов и тем
- **Чтение обсуждений**: просмотр сообщений в темах
- **Участие в дискуссии**: создание новых тем и ответов
- **Поиск**: поиск по темам и сообщениям

## Технологический стек

### Backend
- Python 3.11+
- Django 4+ + Django REST Framework
- SQLite (dev) / PostgreSQL (prod)

### Frontend
- React 18+
- TypeScript/JavaScript (ES6+)
- React Router для навигации
- Axios для HTTP-запросов
