# BlablaForum

Современный форум для общения с Django бэкендом и React фронтендом.

## 📋 Описание проекта

BlablaForum - это полнофункциональное веб-приложение форума, которое позволяет пользователям:
- Создавать и обсуждать треды
- Комментировать и лайкать посты
- Просматривать профили других пользователей
- Управлять контентом через админ-панель

## 🏗️ Технологический стек

### Бэкенд
- **Django 5.2** - веб-фреймворк
- **Django REST Framework 3.15.2** - API
- **SQLite** - база данных
- **Token Authentication** - аутентификация
- **Django CORS** - поддержка CORS

### Фронтенд
- **React 18** - UI библиотека
- **React Router** - маршрутизация
- **Axios** - HTTP клиент
- **React Icons** - иконки
- **CSS Modules** - стилизация

## 🛠️ Установка и запуск

### Требования
- Python 3.8+
- Node.js 16+
- npm или yarn

### Установка бэкенда
```bash
# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r backend/requirements.txt

# Применение миграций
cd backend
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Запуск сервера
python manage.py runserver
```

### Установка фронтенда
```bash
# Переход в папку фронтенда
cd frontend/blablaforum

# Установка зависимостей
npm install

# Запуск сервера разработки
npm start
```

## 📡 API Эндпоинты

### Аутентификация
- `POST /api/register/` - Регистрация пользователя
- `POST /api/login/` - Вход пользователя
- `GET /api/verify-token/` - Проверка токена

### Треды
- `GET /api/threads/` - Список всех тредов
- `POST /api/threads/` - Создание треда
- `GET /api/threads/{id}/` - Детальная информация о треде
- `PUT /api/threads/{id}/` - Обновление треда
- `DELETE /api/threads/{id}/` - Удаление треда

### Комментарии
- `GET /api/threads/{id}/comments/` - Комментарии треда
- `POST /api/threads/{id}/comments/` - Создание комментария

### Лайки
- `POST /api/threads/{id}/like/` - Лайкнуть тред
- `DELETE /api/threads/{id}/like/` - Убрать лайк

### Профиль
- `GET /api/profile/` - Профиль пользователя
- `GET /api/profile/threads/` - Треды пользователя
- `GET /api/profile/liked/` - Лайкнутые треды

### Админка
- `GET /api/admin/stats/` - Статистика сайта

### Теги
- `GET /api/tags/` - Список тегов
